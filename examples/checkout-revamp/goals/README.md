# Goals

Record long-lived project outcomes, constraints, and acceptance criteria here. A goal may span many tasks and runs.

Use Markdown for the explanation: problem, outcome, scope, doneWhen conditions, and evidence required. YAML frontmatter MAY carry stable metadata such as id, status, owner, and method. A matching JSON file is a machine-readable index for filtering and joins; OKR, milestones, experiments, and metrics are optional methods.
