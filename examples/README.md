# Examples

| Example | What it shows |
| --- | --- |
| [`checkout-revamp`](checkout-revamp) | A project mid-flight: one goal, six tasks across two repositories in every state, a design decision, a Codex work log, and a Codex → Claude Code handoff. Run `hp brief` inside it, or open it with any agent and ask it to continue. |

`build-checkout-revamp.sh` rebuilds the example with the `hp` CLI (`sh examples/build-checkout-revamp.sh` from the repository root), so it stays valid as the CLI evolves. Source code for the example's `web` and `api` repositories is intentionally not included.
